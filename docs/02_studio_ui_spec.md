# SonataRack Hardware UI

SonataRack'ı, sıcak fıstık ve krem tonlarında minimalist bir dokunuşla tasarladım. Her panelden tutunabilir SVG rotary düğmeler, iki oktavlık klavye, 16 adımlı Euclidean poliritm gridi, canlı WebAudio osiloskop ve FFT spektrum grafiklerini içeren ayrılmış yüzeyler oluşturuldu. Preset deposu ve WAV indirme seçenekleri de dahil edilmiştir.
